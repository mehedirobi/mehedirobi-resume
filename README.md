# Mehedi Robi — Resume

A clean, modern, and responsive personal resume built with React.js and Vite. The project presents professional experience, technical skills, projects, education, certifications, and contact information in a structured, recruiter-friendly format.

## Features

* Fully responsive design for mobile, tablet, and desktop
* Clean and modern resume layout
* Component-based React architecture
* Print-friendly and PDF-ready layout
* Fast development and build performance with Vite
* Easy-to-maintain structured sections
* Direct links to portfolio, GitHub, LinkedIn, and project demos
* Optimized spacing and typography for professional presentation

## Tech Stack

* React.js
* Vite
* JavaScript (ES6+)
* Tailwind CSS
* HTML5
* CSS3

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mehedirobi/mehedi-robi-resume.git
```

### 2. Navigate to the project directory

```bash
cd mehedi-robi-resume
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

### 5. Build for production

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

## Customization
